# 功能说明

Skill Manager 管的是你自己的技能库，再部署到本机的编码 Agent 和龙虾 Agent。下面按侧栏说明「这里是干什么的」，不写实现细节。

## 技能库 / 龙虾技能库

两个管理域，同一座 SkillManagerVault。编码技能要先进入龙虾库，才能部署给龙虾 Agent。

- 列表看原名、中文注释、标签、部署状态。
- 详情维护注释、分类、标签、支持声明、覆盖层；读译文或原文。译文不是部署正文。
- 部署把合成副本写到本机目标（Agent 目录、共享目录、Hermes default 等）。撤销只动这台机器上的副本。
- 上游更新：查看来源变化，确认后再采用。跨电脑同步的是已经采用的库，不是重新入库。
- 归档：暂时不用的技能移出正常列表，随库同步；已有受管部署要先卸干净。

## 预设

一组技能的可复用组合，定义随库走。部署是「叠加上去」，撤销按成员执行，不记「当初是哪个预设装上的」。

## Hermes 档案

龙虾技能先部署到 default，再在其他档案里明确启用。档案详情只读，改内容回技能库。当前不在本软件里创建或删除档案。

## 工具中心

登记没有图形界面、容易忘掉的本机工具：简介、维护指南、版本检查命令随库同步；**是否已安装、装在哪**是这台机器自己的记录。真正安装由外部 Agent 做，软件负责检查和生成任务说明。

## 设置

- 本机检测到的 Agent：启停、顺序、技能目录。
- 外观、检查频率、库同步状态、诊断。
- 共享技能目录按当前用户主目录识别，只读。
- 「软件版本」可以检查桌面应用更新。经管理站打开的网页没有托盘、关窗收起和应用更新。

## 管理对话

当前这台 Host 上的对话，不是把步骤复制到 Cursor 里。软件会带上当前库和当前页面的摘要；删除技能或覆盖部署仍要在界面确认。没有人下指令时，它不会自己巡检或 push。
