# 技能库跨电脑同步与本机部署的边界

SkillVault 跨电脑同步技能内容及管理资料，包括 `.manager`、预设组合定义、Agent（代理）指令源内容和工具中心共享资料（工具登记、简介、维护指南、版本检查命令）；技能部署记录、指令分发目标、Hermes 档案技能启用名单及工具本机安装记录由各电脑独立维护。同步完成后更新本机已有技能部署，新增技能的首次部署按用户命令执行，指令具体分发行为另行设计。这样可以共享维护成果，同时让每台电脑分别决定使用哪些 Agent 及技能组合。

2026-10-15 扩展：工具中心共享资料纳入同步范围、工具本机安装记录归入本机状态，依据工具中心跨电脑共享讨论（见[需求记录](../requirements.md)工具中心章节）。

本裁决依据本项目需求访谈，见[需求记录](../requirements.md)。具体库格式、同步实现和其他状态边界另行讨论。
