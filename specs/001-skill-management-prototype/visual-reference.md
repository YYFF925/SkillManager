# UI 视觉参考：沿用 FeiSkillDock 界面风格

本说明依据用户的最新要求：整体界面风格不准备大动。
业务与交互范围以同目录的 [原型规格](spec.md) 为准；本文件说明已有视觉语言如何延续。
颜色、字号和布局数字来自旧版源码，用于建立视觉基线，不作为正式产品不可修订的规格。

界面细节的源码核查与原型差异见[交互细节核查](ui-interaction-audit.md)。后续改动先核对对应旧组件的布局、悬停、选择、反馈与操作位置，再按新业务调整；不要只保留配色而另造整套交互，也不要机械恢复旧业务。

## 原型制作与迭代说明

> 这是 FeiSkillDock 的新产品原型，整体视觉沿用现有软件，在熟悉的桌面工具界面里改善技能管理流程。
>
> 请读取 spec.md 理解完整业务，读取本说明了解视觉基线，并结合我附上的旧版技能库和 Agent 技能列表截图。
> 沿用左侧分组导航、右侧内容区、顶部搜索和操作工具栏、紧凑卡片／列表、浅灰底色、
> 白色面板、绿色强调色、柔和多色标签、细边框、轻阴影和系统中文字体。
> 保持现有的信息密度、圆角和图标风格，让它看起来仍然是同一类熟悉的技能管理工具。
>
> 新的来源入库、上游变化、自己的库同步、管理资料及部署操作，应使用同一套视觉语言。
> 可以根据新业务调整分组、操作入口、详情组织和步骤衔接，但不进行整套视觉重设计。
> 截图中的首页、项目管理、工具中心和其他旧入口只说明旧版样式，不要求恢复到本轮原型。
> 已有源码中的演示占位也不能代替 spec.md 要求的可操作流程。
>
> 请交付能点击并产生模拟状态变化的交互原型。主流程和结果反馈以 spec.md 为准；
> 不将虚构数据、场景切换或界面视觉参数转成新的产品机制。

## 外壳与信息密度

| 元素 | 旧版基线 | 延续方式 |
|---|---|---|
| 左侧导航 | 宽约 220px，淡灰底，右侧细分隔线 | 保留比例、分组标题、折叠组、选中底色及数量徽标；内容按新业务调整 |
| 主内容 | 自适应；旧版源码最大宽约 1200px，外侧留白约 20px | 延续工具型桌面界面的内容宽度和密度；当前实现后续已放宽到 1440px |
| 页内标题区 | 标题、路径或数量说明；右侧搜索与主要操作 | 让用户知道当前查看的库、Agent 或来源，以及当前动作影响范围 |
| 工具栏 | 输入框和常规按钮高约 40px，线性图标、紧凑间距 | 入库、检查、同步和多选使用同样尺寸与形态 |
| 技能网格 | 桌面常见三列，较窄时两列，卡片间距约 12px | 避免为了视觉展示把卡片扩大成低密度展板 |
| 技能列表 | 状态点、原技能名、描述、标签、状态和操作 | 保持快速扫描，中文短注释按新需求补入 |
| 面板与卡片 | 圆角约 12px，细边框，轻阴影 | 保留整体形态；新面板采用同一语言 |
| 小控件 | 按钮／输入框圆角约 8px，导航行约 6px | 延续旧控件的尺度 |

以上是旧版参考尺寸。设计者可为可读性和新内容适度调整，不要求像素级复刻。

**后续修订（2026-10-17）**：当前实现为让宽窗口下的技能卡片更充分，主内容最大宽调整为约 1440px，分类列由 152px 收窄为 132px，列间距为 16px。旧版 1200px/152px 仅保留为历史参考。

预设详情的预设列表宽 180px，与成员区间距 16px；成员卡片按实际可用宽度排列，每列至少约 400px，空间不足三列时显示两列。标题优先完整显示技能名，超长名称可换行，中文注释在剩余空间内省略并可悬停查看全文。

预设导航调整（2026-10-17）：主侧栏在「工具中心」下方显示同级「预设」入口，取消「编码预设 → 全部预设」分组及卡片总览；直接进入页内列表与成员浏览。管理域切换、新建与预设行操作保留在页内列表。此调整取代旧原型的分组总览导航，行为见 002 规格 FR-025。

部署目标与库页密度（2026-10-17）：GUI 部署弹窗在编码库的单项、多选与预设选择中增加「共享 Agent」目标，与普通 Agent 同列展示、同样按真实部署状态亮显，无已检测 Agent 时仍保留该项。库列表把当前系统不适用的技能排到受支持技能之后，灰显样式不变。

悬浮提示（2026-10-18）：悬浮提示不再使用系统 `title` 原生提示，改为自绘提示层并以 portal 渲染到页面根，按视口边缘自动翻转与收边（触发元素上方空间不足时移到下方）；样式沿用现有面板的圆角、边框与配色。原型未单独定义提示层视觉，此为实现补充。

分类栏滚动（2026-10-29）：技能库、Hermes 档案、预设详情与工具中心的左侧分类栏固定在工具栏／标签栏下方，与右侧卡片区分滚动；分类未超出可视高度时不显示滚动条，仅内容溢出时出现。页头、搜索与筛选保持在分类栏之上，不随卡片滚走。 同日将产品分类列由 132px 加宽为 148px，使五个汉字分类名（如「知识库管理」）在计数旁仍可完整显示；更长名称继续省略。

## 文字与图标

- 系统无衬线中文字体；旧版字体顺序包含 SF Pro Text、PingFang SC、Noto Sans SC、
  Microsoft YaHei 及系统回退字体。路径及文件内容使用等宽字体形态。
- 页标题约 17px、半粗；技能名约 14px、半粗；说明及常规操作约 13px；
  状态约 12px；标签约 11px。字号是视觉参考，不限制后续用户字号设置。
- 通用操作使用旧版 Lucide 风格的线性图标，通常 14—16px；Agent 品牌图标保留识别性。
  本条说明图标形态，不要求新原型采用旧版技术栈。

## 技能卡片与状态表达

卡片沿用“顶部名称与状态点 → 内容说明 → 多标签 → 底部状态与操作”的组织。
文件数量可放在顶部右侧；底部通过细分隔线区分状态和内容。
网格／列表、搜索、标签筛选和多选操作应保持同一套视觉密度。

- 受管技能：绿色小圆点，加“已同步”等状态文字。
- 未受管技能：弱化圆点、“仅本地”，提供收编入口；可沿用上传图标。
- 本地有变更：醒目的状态文字和柔和警示色，按规格暂停该项覆盖。
- 上游更新与新增：明确标记及数量，可进入变化清单。
- 系统不适用：整项灰化，仍能读懂原因。

只继承状态表达的视觉形态，实际状态转换以 spec.md 为准。
界面要清楚区分上游更新与自己的库同步，具体入口位置可以通过原型体验调整。
